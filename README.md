# NestJS Knowledge

Repositorio personal de aprendizaje y referencia sobre **NestJS**.

Este proyecto contiene ejemplos prácticos, fragmentos de código y conceptos documentados mientras aprendo y profundizo en el ecosistema de NestJS.

La idea es utilizarlo como una base de conocimiento a la que pueda volver posteriormente para consultar implementaciones y conceptos específicos.

## Contenido

Actualmente, el repositorio contiene ejemplos relacionados con:

- Controllers
- Services
- Modules
- Dependency Injection
- DTOs
- Pipes
- Custom Pipes
- Guards
- Middleware
- Exception Handling
- Validation
- Swagger
- Prisma
- MySQL
- Configuration
- CORS
- HTTP status codes
- Y otros conceptos del ecosistema NestJS
